Instruções no Windows:

Opção 1 - Usar direto no navegador (mais simples):

  1. Clique no link acima
  2. Quando abrir a página, pressione Ctrl + S no teclado
  3. Na janela que abrir, escolha Área de Trabalho ou Documentos
  4. Em Tipo, deixe Página da Web, Completa ou HTML
  5. Clique em Salvar
  6. Depois é só clicar 2 vezes no arquivo salvo para abrir — vai funcionar offline com todos os animais que cadastrar

Opção 2 - Instalar como APP no Windows (recomendado):

  1. Clique no link acima para abrir o APP
  2. No Google Chrome ou Microsoft Edge, no canto direito da barra de endereço vai aparecer um ícone de instalar (monitor com seta ↓) ou 3 pontinhos
  3. Clique em Instalar ou vá no menu ⋮ > Salvar e compartilhar > Instalar página como app (Chrome) ou ⋯ > Aplicativos > Instalar este site como aplicativo (Edge)
  4. Confirme em Instalar
  5. Pronto! Vai criar um ícone "Adriano Apolinário - Cofre Genealógico Alta Elite" na sua Área de Trabalho e no Menu Iniciar, com sua logo dourada — abre como um programa normal, sem barra do navegador

Opção 3 - Criar atalho na Área de Trabalho:

  1. Clique no link do APP com botão direito → Salvar como
  2. Salve na Área de Trabalho como Cofre-Adriano.html
  3. Clique com botão direito no arquivo salvo → Enviar para → Área de trabalho (criar atalho)
  4. Clique com botão direito no atalho → Propriedades → Alterar ícone → escolha sua logo se quiser

Onde ficam os dados?

Todos os animais que você cadastrar ficam salvos automaticamente no seu computador no navegador (localStorage cofre_alta_elite). Mesmo offline funciona.

Para fazer backup: Dentro do APP vá em Configurações → Exportar Dados (se tiver) ou copie o arquivo. Se trocar de computador, é só importar.
